📚 التحليل الأمني والوقاية من ثغرات DOM-Based XSS

🔴 خطورة الخاصية innerHTML

عند إسناد قيمة نصية غير موثوقة إلى innerHTML، يقوم متصفح الويب بتمرير السلسلة إلى مفسر الـ HTML (HTML Parser).

  • تُترجم الوسوم وعناصر الـ HTML كأوامر هيكلية.
  • يتم تشغيل دوال الـ JavaScript المضمنة في معالجات الأحداث مثل onerror أو onload تلقائياً فور محاولة المتصفح تحميل المورد.

🟢 الحماية باستخدام textContent

تتعامل الخاصية textContent وكذلك document.createTextNode() مع المدخلات كقيمة نصية بحتة (Raw String).

  • يتم تحييد المحارف الخاصة مثل < و > و & تلقائياً من قِبل المتصفح.
  • لا يتم استدعاء مفسر HTML نهائياً، مما يبطل مفعول أي Payload خبيث ويمنع تنفيذ الأكواد كلياً.
